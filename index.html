Projects

MSR: Markovian Semantic Relatedness

Demo coming soon

Unsupervised query expansion and cross-language search. MSR builds a term co-occurrence graph, runs a Markov-chain walk toward a root term, and scores every term by z-scored hitting time. The result is a weighted concept that can rank untranslated foreign-language text for an English query, without machine translation.

I designed MSR and led the project as a U.S. Government researcher (2019–2022). This is a from-scratch reimplementation.

Python · NumPy/SciPy · spaCy · FastAPI · Celery · RabbitMQ · PostgreSQL · Next.js · Docker

CHIP: Confounding Hash Iteration for Passwords

Live demo

An iterated password hash that keeps hashing until it has seen a set number of collisions among the low bits of its digests, so the iteration count depends on the password and salt in a way you can't predict without running the whole chain.
